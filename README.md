# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**.
This project demonstrates basic DOM manipulation, event handling, and core game logic in JavaScript.

---

## 🧩 Features

* 🎯 Two-player game (X vs O)
* 🔄 Reset game option
* 🆕 New game button after winner announcement
* 🏆 Displays winner clearly
* 🎨 Clean and responsive UI
* 📱 Works on desktop and mobile screens

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling and layout
* **JavaScript (ES6)** – Game logic and interactions

## 🎮 How to Play

1. The game starts with **Player X**
2. Players take turns clicking on empty boxes
3. First player to align **3 symbols** (row, column, or diagonal) wins
4. Winner is displayed on the screen
5. Click **New Game** or **Reset Game** to play again

---

Example Board Layout:

```
X | O | X
---------
O | X | O
---------
X |   |
```

---

## 🧠 Game Logic (Overview)

* Uses a boolean flag to switch turns between players
* Stores winning patterns in an array
* Disables a box once clicked
* Checks for a winner after every move
* Displays a message container when the game ends
